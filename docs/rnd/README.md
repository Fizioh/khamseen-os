## Boundaries
- Do not conflate research proofs with installed/running Khamseen OS capabilities.
- Do not duplicate production observability, sandbox, provider integration, or harness core.
- Never report a measurement without linked fixture, model/provider version, executable tests and log provenance.
- `Fizioh/GeoAgent` is an existing fork of upstream GeoAgent, not this project's new repository.
- Standalone repositories (`khamseen-agent-runtime-benchmark`, `khamseen-geospatial-agent`, `khamseen-alphaevolve-mini`) are proposals only; no creation is claimed.
